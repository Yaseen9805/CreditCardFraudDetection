# 💳 Credit Card Fraud Detection

A machine learning project to detect fraudulent credit card transactions using classification algorithms.

---

## 📂 Dataset

The dataset is **not included** due to GitHub size limits.

👉 Download from:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Place it inside the `dataset` folder.

---

## ⚙️ Features

* Data preprocessing
* Fraud detection using ML models
* Evaluation using precision, recall, F1-score

---

## 🧠 Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

---

## 🚀 How to Run

```bash
git clone https://github.com/Yaseen9805/CreditCardFraudDetection.git
cd CreditCardFraudDetection
```

Run the script:

```bash
python CreditCardFraud.py
```

Or use:

```bash
run.bat
```
